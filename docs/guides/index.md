# Guides

These guides cover each major use of the library with Rust and Python examples.

- [Stream configuration](configure.md): the Nominal URL, batching and backpressure, metrics, and errors.
- [Write points](write.md): streaming data in all supported data types
- [Fallback file](fallback.md): save the points a stream couldn't send, and upload them later.
- [Stream files](files.md): keep a file of every point, read a stream file, and upload it to Nominal.
- [Stream logs](logs.md): send log messages with arguments to log channels, and check their delivery.

See [Examples](../examples/index.md) for complete applications.
