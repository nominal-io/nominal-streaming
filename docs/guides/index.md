# Guides

These guides go further than the [quickstart](../index.md). Each has Rust and Python examples.

- [API Keys Setup](api-keys-setup.md): copy your API key and base URL, and save them in a profile.
- [Write points](write.md): each value type, timestamps, batches, structs, arrays and tags.
- [Configure a stream](configure.md): the Nominal URL, batching and backpressure, metrics, errors, and closing the stream.
- [Stream files](files.md): keep a fallback file or a file of every point, read it, and upload it to Nominal.
- [Stream logs](logs.md): send log messages with arguments to log channels, and check their delivery.

For complete programs, see [Examples](../examples/index.md).
