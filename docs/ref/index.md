## Python client

The [Python client](https://dev.nominal.io/python/) has a higher-level API for streaming, built on `nominal_streaming`. Unless you need `nominal_streaming` by itself, use the client's [write stream](https://dev.nominal.io/python/guides/streaming/overview/).
